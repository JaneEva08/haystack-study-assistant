# Haystack Study Assistant

**[Отчёт по заданию](HOMEWORK.md)**

Telegram-бот на Haystack Agent с памятью SQLite/Pinecone и тремя
инструментами: факт о кошках, анализ случайного изображения собаки,
погода по названию города через Open-Meteo. Новый инструмент — get_weather.

## Запуск

Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопировать .env.example в .env и заполнить ключи. Индекс Pinecone:
dense, 1024, cosine. Чат и анализ изображений используют CHAT_MODEL
через OPENAI_BASE_URL. Модель должна поддерживать tools и изображения.

```bash
python -m unittest -v
python probe.py
python bot.py
```

probe.py выполняет реальные запросы к внешним сервисам и модели,
использует отдельный тестовый namespace и сохраняет результаты в results/.
Боту нужен работающий процесс и интернет. Автозапуска после перезагрузки нет.
С одним токеном допускается один polling-процесс.

## Инструменты

- get_cat_fact — GET catfact.ninja/fact; ответ приписывается внешнему
  источнику и не объявляется проверенным учебным знанием.
- analyze_dog_image — GET Dog CEO, загрузка JPEG/PNG, проверка типа и размера,
  передача байтов через ImageContent в отдельный OpenAIChatGenerator.
  Описание не выводится из имени файла. Telegram получает картинку и подпись.
- get_weather(city) — геокодирование, затем текущие данные Open-Meteo;
  сохраняются город, страна, часовой пояс, время, значения и единицы.

Промпт явно указывает, когда вызывать каждый инструмент и как сообщать
об ошибках. Haystack ограничен шестью шагами агента; инструменты выполняются
последовательно. Телеметрия Haystack отключена в коде.

## Память

В Pinecone сохраняются только исходные сообщения пользователя с type=user_message.
Ответы агента, результаты API, картинки, описания и команды туда не записываются.
В SQLite хранится короткий диалог. Pinecone-поиск выполняется до ответа;
его результат передаётся модели как прежние сообщения ученицы, не как правила.
Для этой версии используется отдельный префикс namespace vpg06.

Фильтр повторов из VPg05: cosine 0.95, дополнительные признаки отрицания
и чисел. Namespace и user_id разделяют пользователей.
Это эвристика, не универсальное распознавание противоречий.

/start, /help — команды; /lesson — новый учебный контекст;
/memory_on, /memory_off — управление памятью; /status и /memory_status — состояние;
/reset — очищает короткий контекст и переключает активную версию namespace.
Старые облачные записи не уничтожаются, но исключаются из поиска.

## Проверки и ограничения

14 локальных тестов: память, повторы, изоляция, сброс, исходный текст,
ошибки записи, внешние данные, погода с единицами и временем, неверные
изображения, ограничения адресов. Реальные проверки Haystack и сервисов
сохранены в results/service-checks.json без ключей и байтов изображения.

Породу по фото нельзя считать установленной. Геокодер выбирает первый
результат и показывает город/страну; неоднозначное название следует уточнить.
Погодные значения — модельные данные сервиса, не показания домашнего датчика.
Результаты API требуют оценки достоверности. При сбоях инструменты
возвращают ошибку, а не заготовленный успешный ответ.
Короткая история ограничена 20 парами. Обработка Telegram-запросов
последовательная; атомарная доставка и одновременная работа нескольких
экземпляров не реализованы.
